# Afrique-Con Mono-Repo

Welcome to the Afrique-Con mono-repo. This repository contains all components of the system.

- **[frontend](file:///d:/AFRIQUE/Afrique-Con/frontend)**: Frontend application.
- **[gateway](file:///d:/AFRIQUE/Afrique-Con/gateway)**: API gateway service.
